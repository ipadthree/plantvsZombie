# Horse Missile Zombie artwork

Generated with the built-in `image_gen` tool, using the user's `horse_zombie.gif` and the game's Log Zombie as references. Exact generation/edit prompts are recorded in [prompts.json](prompts.json).

- `ready.png`: left-facing zombie/horse team with three loaded red-tipped missiles.
- `recharging.png`: matching team with three empty launcher tubes and smoke.
- `horse.png`: standalone horse for the survivor phase.
- `missile.png`: left-facing projectile with exhaust.

Original RGBA PNGs are retained here. Runtime WebP exports are in `public/assets/horse-missile-zombie/`, preserving genuine alpha transparency. Character feet align with the lane baseline; missile flight, targeted tiles, and impact flashes are animated by the game's clock.
