# T rex Zombie artwork

Created with the built-in `image_gen` tool from the user's `TRex_zombie.gif`, matching the game's painted cartoon style. Exact prompts are saved in [prompts.json](prompts.json).

- `ready.png`: left-facing armored T rex, zombie knight, flag, chain and metal ball.
- `released.png`: matching pose after letting the ball go; no chain or attached ball.
- `ball.png`: standalone iron ball monster for rolling animation.

Original transparent RGBA PNGs live here; optimized WebP game assets are in `public/assets/t-rex-zombie/`. The game animates stomping, biting, and ball rotation using its pause-aware clock. The board's position and dimensions stay unchanged.
